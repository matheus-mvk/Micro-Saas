# Scripts

- `pnpm dev`: run API and web in development.
- `pnpm build`: build all packages and apps.
- `pnpm lint`: lint all workspaces.
- `pnpm typecheck`: run TypeScript checks.
- `pnpm test`: run unit/component tests.
- `pnpm test:e2e`: run e2e suites.
- `pnpm db:generate`: generate Prisma client.
- `pnpm db:migrate`: run local Prisma migrations.
- `pnpm db:seed`: seed local data.
- `pnpm docker:up`: start Compose stack.
- `pnpm docker:down`: stop Compose stack.
